# PRD: 포헤르츠 × 잇퓨 듀얼 캠페인 인플루언서 모집 페이지

**문서 버전**: v1.0  
**작성일**: 2026-04-16  
**상태**: 기획 초안  
**작업 환경**: 로컬 HTML 단일 파일 → Vercel 배포 (신규 프로젝트, teumgyul과 별도)

---

## 1. 배경 및 목적

### 1.1 배경
시리아이(SIRIAI)는 두 뷰티 브랜드의 인플루언서 캠페인을 동시에 운영한다.

| 캠페인 | 브랜드 | 제품 |
|--------|--------|------|
| A | 쿼드쎄라 × 포헤르츠 (의료뷰티 스킨케어) | 포헤르츠 버블세럼 70ml |
| B | 잇퓨 (ITFU) | 순율크림 + 순율앰플 |

기존 oddtype-invite 방식처럼 단일 신청 페이지에서 두 캠페인을 동시에 모집하되, 인플루언서가 **원하는 캠페인을 선택해 중복 지원**할 수 있어야 한다.

### 1.2 목적
- 단일 링크로 두 캠페인 동시 모집 → 운영 효율 극대화
- 중복 지원 허용으로 인플루언서 참여율 제고
- 지원 데이터를 구글 시트로 자동 수집 → 선발 프로세스 간소화
- 시리아이 브랜드 감도에 맞는 고품질 UI/UX

## 2. 사용자 및 시나리오

**대상**: 뷰티 인플루언서 (Instagram 중심, 팔로워 규모 무관)

**핵심 시나리오**
1. 인플루언서가 링크 수신 → 페이지 접속
2. 두 캠페인 정보 확인 (제품, 조건, 가이드라인)
3. 지원할 캠페인 선택 (A만 / B만 / A+B 중복 모두 가능)
4. 개인정보 + 소셜 계정 입력
5. 제출 → 구글 시트 자동 기록

## 4. 기능 요구사항

### 4.1 캠페인 선택 (핵심)
- 캠페인 A, B를 **각각 독립적으로 선택/해제** 가능 (체크박스 방식)
- **최소 1개 이상** 선택해야 다음 단계로 진행
- 선택된 캠페인에 따라 이후 단계에서 **해당 가이드라인만 노출**
- 중복 선택 시 두 캠페인 모두 가이드라인 확인 유도

### 4.2 멀티스텝 폼 구조

```
[Step 0] 랜딩 — 캠페인 소개 + "지원하기" CTA
[Step 1] 캠페인 선택 — A / B / A+B (중복) 선택
[Step 2] 캠페인 가이드라인 확인 — 선택한 캠페인 조건 동의
[Step 3] 개인정보 입력 — 이름, 연락처, 연령대, 배송 주소
[Step 4] 소셜 계정 입력 — 인스타그램 링크 (필수), 기타 플랫폼 (선택)
[Step 5] 최종 확인 + 제출
[Step 6] 완료 화면 — 제출 완료 안내 + 다음 스텝 안내
```

### 4.3 가이드라인 확인 단계 (Step 2)
- 선택한 캠페인 수에 따라 탭 또는 아코디언으로 분리 표시
- 각 캠페인별 **필수 동의 체크박스** (공동작업자 설정 동의, 2차 활용 동의)
- 동의 완료 후 다음 단계 활성화

### 4.4 개인정보 입력 (Step 3)
| 필드 | 타입 | 필수 |
|------|------|------|
| 이름 | text | ✅ |
| 연락처 | tel | ✅ |
| 연령대 | select | ✅ |
| 배송 주소 | text | ✅ |
| 상세 주소 | text | ✅ |

### 4.5 소셜 계정 입력 (Step 4)
| 필드 | 타입 | 필수 |
|------|------|------|
| 인스타그램 URL | url | ✅ |
| 유튜브 URL | url | ❌ |
| 틱톡 URL | url | ❌ |

### 4.6 응답시트 연동
- Google Apps Script 웹훅 (POST) 으로 데이터 전송
- **구글 시트 컬럼 구조**:

| 컬럼 | 내용 |
|------|------|
| 제출시각 | 타임스탬프 |
| 지원캠페인 | 포헤르츠 / 잇퓨 / 포헤르츠+잇퓨 |
| 이름 | 텍스트 |
| 연락처 | 텍스트 |
| 연령대 | 텍스트 |
| 배송주소 | 텍스트 |
| 인스타그램 | URL |
| 유튜브 | URL |
| 틱톡 | URL |
| 포헤르츠_가이드라인동의 | Y/N |
| 포헤르츠_2차활용동의 | Y/N |
| 잇퓨_가이드라인동의 | Y/N |
| 잇퓨_2차활용동의 | Y/N |

- `no-cors` 모드 fetch POST
- 제출 중 로딩 스피너 표시
- 제출 실패 시 재시도 안내 문구 노출

## 5. 디자인 요구사항

### 5.1 디자인 감도
- **시리아이(SIRIAI) 스타일** — 다크 베이스, 고급스럽고 절제된 미니멀리즘
- oddtype-invite 수준 이상의 디자인 완성도 요구

### 5.2 색상 시스템

| 역할 | 값 | 비고 |
|------|-----|------|
| 배경 베이스 | `#0a0a0a` | 딥 블랙 |
| 서피스 | `rgba(255,255,255,0.05)` | 글래스모피즘 |
| 포헤르츠 액센트 | `#b8f5e0` 또는 `#e8f5e9` | 버블 세럼 → 클린 그린 계열 |
| 잇퓨 액센트 | `#d4c5a9` 또는 `#c9b48a` | 율무·한방 → 웜 베이지/골드 계열 |
| 텍스트 기본 | `#ffffff` | |
| 텍스트 보조 | `#888888` | |

> 두 캠페인의 액센트 컬러를 구분해 각 섹션·카드에 적용, 시각적으로 캠페인 정체성 분리

### 5.3 타이포그래피
- 본문: Pretendard Variable
- 포인트 헤드라인: 영문 세리프 (Times New Roman 또는 유사 계열)
- 폰트 위계: 브랜드명 > 섹션 타이틀 > 본문 > 캡션

### 5.4 UI 패턴
- 글래스모피즘 카드 (`backdrop-filter: blur`)
- 앰비언트 글로우 배경 (두 캠페인 컬러 orb)
- 프로그레스 바 (상단 고정, 스텝 진행 시각화)
- 부드러운 스텝 전환 애니메이션 (slideUp)
- 모바일 퍼스트, 최대 너비 560px

### 5.5 캠페인 카드 디자인
- 각 캠페인 선택 카드에 **제품 이미지 영역** 포함
- 선택 상태: 액센트 컬러 테두리 + 글로우 이펙트
- 미선택 상태: 반투명 그레이 테두리
